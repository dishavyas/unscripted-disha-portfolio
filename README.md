# Unscripted Disha Portfolio

An immersive parallax website with animated scenery, storytelling chapters, and responsive navigation.

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` from this folder.

## Publish with GitHub Pages

In Settings → Pages, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.
